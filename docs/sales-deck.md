# dentia（デンティア）
## 歯科専用 AIカルテ下書き生成

**「カルテ入力の時間を、患者と向き合う時間に。」**

診療を録音するだけで、歯科のSOAPカルテ下書きを自動生成。

---

## こんな課題はありませんか？

- 診療後の**カルテ入力に時間がかかり、残業**になりがち
- 入力に気を取られ、**患者と向き合う時間が削られる**
- 歯式・検査値・処置内容など、**歯科特有の記載が手間**
- 記録の**書き方・抜け漏れ**が人によってばらつく

> カルテ業務の負担が、診療の質と働き方を圧迫しています。

---

![bg right:50% fit](../project/screenshots/01-rec.png)

## dentia とは

診療の会話を**録音するだけ**で、AIが歯科の **SOAP形式カルテ下書き** を生成します。

- **S** 主訴・問診 / **O** 口腔内所見
- **A** 評価・診断 / **P** 治療計画
- 歯科に特化した記載
- 結果はコピー → カルテへ

> → 右が実際の画面です。

---

![bg right:50% fit](../project/screenshots/01-rec.png)

## 使い方はシンプル（3ステップ）

1. **録音**（または会話を貼り付け）
2. テンプレを選んで **「SOAPを生成」**
3. 結果を**確認・加筆 → コピー**

- 録音が使えない時は**手入力**でもOK
- PC・タブレット・スマホのブラウザ対応

---

![bg right:54% fit](../project/screenshots/full.png)

## 生成結果のイメージ

**S / O / A / P** の4ブロックで構造化。

- 歯式・検査・処置が自然に記載
- 生成時間を画面に表示（数秒）
- **「コピー」**でカルテへ貼り付け

> A（評価・診断）は断定を避けた表現。
> 最終確認は歯科医師が行う前提です。

---

![bg right:48% fit](../project/screenshots/full.png)

## 歯科に特化しているから自然

- **歯式**：#46 / #36 など
- **検査**：冷水痛・打診痛・EPT・PD・BOP
- **処置**：抜髄・感染根管治療・SRP・補綴・RCF
- **処置別テンプレ**：初診／再診／SPT／補綴／根管治療

> 「#36 急性根尖性歯周炎、失活歯。感染根管治療の適応」
> のように歯科表現で下書き。

---

## 仕組み（2段のAIが連携）

```
診療を録音
   ↓  AI① 文字起こし（音声 → テキスト）
会話テキスト
   ↓  AI② SOAP生成（テキスト → 歯科SOAP）
S / O / A / P のカルテ下書き
```

録音 → 自動で文字起こし → 歯科SOAP生成 まで、ひと続きで自動実行。

## 安心・安全への配慮

- **ログイン**制（医院アカウント）で利用を保護
- **医院単位のデータ分離**（他院・他人のカルテは見えない設計）
- 録音した**音声はサーバーに保存せず、文字起こし後に破棄**
- **A（評価・診断）は断定を避け、最終確認は歯科医師**が行う前提

> ※ 医療情報の取扱い（暗号化・監査ログ・各種ガイドライン準拠等）は
> 　 継続的に強化していきます。
