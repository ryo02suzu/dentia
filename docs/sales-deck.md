# 01. dentia とは

### CONCEPT
**歯科医師が、目の前の患者さんに集中できる時間を取り戻す。**

---

## こんなお悩みはありませんか？

- 診療しながらの**カルテ入力が負担**で、ミスや抜け漏れが心配
- カルテを書くために**残業**になりがち
- もっと**患者さんと向き合って**診療したい
- 歯式・検査値・処置など**歯科特有の記載に手間**がかかる
- 記録の**書き方・質が人によってばらつく**

> カルテ業務の負担が、診療の質と働き方を圧迫しています。

# 02. 使い方

### 録音 → 文字起こし → SOAP生成

---

![bg right:50% fit](../project/screenshots/01-rec.png)

## 使い方はシンプル（3ステップ）

1. **録音**（または会話を貼り付け）
2. テンプレを選んで **「SOAPを生成」**
3. 結果を**確認・加筆 → コピー**

- 録音が使えない時は**手入力**でもOK
- PC・タブレット・スマホのブラウザ対応
- ログインで**保存**、別端末でも閲覧可

---

## 仕組み（2段のAIが連携）

```
診療を録音
   ↓  AI① 文字起こし（音声 → テキスト）
会話テキスト
   ↓  AI② SOAP生成（テキスト → 歯科SOAP）
S / O / A / P のカルテ下書き
```

録音停止 → 自動で文字起こし → 歯科SOAP生成 まで、ひと続きで実行します。

## dentia の特徴

### 1. 歯科に特化した下書き
歯式（#46）・検査（冷水痛/打診痛/EPT/PD/BOP）・処置（抜髄/SRP/補綴/RCF）を自然に記載

### 2. 処置別テンプレート
初診／再診／メンテナンス(SPT)／補綴／根管治療で書き分け

### 3. 録音でも手入力でも
診療スタイルに合わせて入力方法を選択

### 4. ログインで保存・端末またぎ
生成したカルテを保存、別端末でも閲覧

# 05. 安心・安全

### 患者さんの診療情報を守る設計

---

## データの取り扱い

- **ログイン制**（医院アカウント）で利用を保護
- **医院単位のデータ分離**：他院・他人のカルテは見えない設計（行レベルセキュリティ）
- 録音した**音声はサーバーに保存せず、文字起こし後に破棄**
- 通信は **HTTPS** で暗号化／AIのAPIに送ったデータは**学習に使われない設定**
- **A（評価・診断）は断定を避け、最終確認は歯科医師**が行う前提

> ※ 保存データの暗号化強化・監査ログ・各種ガイドライン（いわゆる3省2ガイドライン）準拠は、
> 　 継続的に整備を進めています。

## 活用シーン（想定ユースケース）

# 09. よくあるご質問

## よくあるご質問

**Q. スマホ（iPhone）で使えますか？**
A. はい。PC・タブレット・スマホのブラウザで利用できます。

**Q. 録音はどうやって行いますか？**
A. 画面のマイクボタンで録音します（マイク許可が必要）。録音が使えない場合は手入力も可能です。

**Q. 生成された内容はそのまま使えますか？**
A. 「下書き」です。必ず歯科医師が確認・加筆して確定してください。

**Q. 電子カルテ・レセコンと連携できますか？**
A. 現在はコピー＆ペーストに対応。連携は今後対応予定です。
