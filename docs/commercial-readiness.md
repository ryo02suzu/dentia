# dentia 商用化レディネス チェックリスト

歯科向けAIカルテSaaSとして「実際の患者データを扱う商用提供」に進むための地図です。
**エンジニア視点の整理であり、法的助言ではありません。** 法務・コンプラ項目は必ず専門家のレビューを受けてください。

最終更新: 2026-06 / 対象: 本番（Render + Supabase）稼働中のMVP

---

## 現状サマリ

- **稼働中**: 録音 →（OpenAI Whisper）文字起こし →（Anthropic Claude）SOAP生成 → ログイン（Supabase Auth）→ カルテ保存（Supabase + RLS）
- **データ分離**: `records` テーブルに RLS（本人の行のみ read/write）を実装・検証済み
- 位置づけ: **動くMVP**。実患者データの商用提供には下記の対応が必要

### ✅ 対応済み：APIの認証（旧・最重要ギャップ）
- フロントのログイン（Supabase Auth）と DB の RLS に加え、
  `POST /api/transcribe` ・ `POST /api/generate` に **Supabase JWT 検証**を追加（未ログインの直叩きは `401`）。
- あわせて**ユーザー単位のレート制限**（1分あたり上限）で課金暴走を抑止。
- ※ `SUPABASE_*` 未設定の環境では従来どおり通す（ローカル/デモの安全網）。

## 3.5 歯科特化の深掘り（「歯科版Medimo」の芯）

汎用ツール（Medimo等）に対する差別化は、**歯科特化の深さ**にある。

- [x] **歯科初診テンプレの強化**：医科と異なり「全顎ベースライン」。歯式単位のO、歯周基本検査(PD/BOP/動揺度/PCR)、来院順の治療計画。**会話・読み上げに無い所見は創作せず「未実施/要確認」**（server.js TEMPLATES.first）
- [x] **歯科用語の文字起こし補正**：Whisperのpromptに歯科語彙（C0-C4/EPT/SRP/RCF/BOP/SPT/歯式 等）を投入し認識をバイアス（`TRANSCRIBE_PROMPT` で調整可）
- [x] **歯式単位の構造化出力（v1）**：Oを歯番ごとに『#46：所見』形式で構造化（プロンプト実装、ライブ/保存/コピー/QRで一貫）。歯番・左右の取り違え防止を明記
- [x] **QRコード転記**：SOAPをQR化し端末スキャナで転記（ネット非経由）。長文はS/O/A/P分割
- [x] **歯周検査の構造化テキスト（v2a）**：読み上げ→歯番ごとに6点法PD/BOP/動揺度/PCR%を構造化（既定6点法・%）。レセコンの歯周モジュールは置換せず所見テキストとして出力（様式フラグメント回避）
- [ ] 歯式構造化v2b：構造化データ＋歯番ごとの編集UI／様式設定（4点法切替等）（読み上げ運用がβで成立したら）
- [x] **場面別・役割別テンプレを拡充（計12種）**：初診/再診/SPT/補綴/根管 ＋ **自費カウンセリング/訪問診療/歯周精密検査(6点法・PCR%)/抜歯・口腔外科/小児/矯正相談/衛生士記録(SOAPIE)**。各場面に最適化したプロンプト＋サンプル会話。創作禁止を維持
- [x] **出力スタイル切替（簡潔/標準/詳細）** — 先生ごとの好みに（完了）
- [x] **生成結果の編集**（S/O/A/Pをその場で編集→コピー/QR/保存に反映、自動保存後の「編集を保存」）— 完了
- [x] **項目別コピー**（S/O/A/Pを個別にコピー＝レセコンの欄ごと貼り付け）— 完了
- [x] **紹介状（診療情報提供書）生成**（会話→紹介状下書き、紹介先指定可）— 完了
- [x] **保存カルテの検索・絞り込み**（キーワード＋処置別フィルタ）— 完了（直近1000件をクライアント側で検索。**それ以前は一覧・検索に含まれない旨を画面に明示**。医院共有で大量化したらサーバー側 ilike 検索／ページングが今後課題）
