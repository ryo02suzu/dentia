# dentia 操作マニュアル（利用者向け）

歯科専用AIカルテ下書き生成「dentia」の使い方です。
診療の会話を録音（または貼り付け）すると、AIが歯科の **SOAP形式カルテ下書き**（S/O/A/P）を作成します。

> ⚠️ **生成されるのは「下書き」です。** 内容を必ずご確認のうえ、加筆・修正して利用してください。
> 評価・診断（A）は断定を避けた表現になっており、**最終的な確定は歯科医師が行う**前提です。

---

## 1. 動作環境

- **ブラウザ**：Safari / Chrome などの最新ブラウザ（PC・タブレット・スマホ対応）
- **録音を使う場合**：マイクの使用許可が必要。セキュリティ上 **HTTPS（`https://…`）** でのみ録音できます
- インストール不要。URLを開くだけで利用できます

---

## 2. ログイン / 新規登録

1. dentia のURLを開く
2. 初めての場合は **「新規登録」** タブでメールアドレスとパスワード（6文字以上）を入力
3. 2回目以降は **「ログイン」** タブからサインイン
4. ログイン状態は保持され、**別の端末でも同じアカウントでログイン**すれば保存したカルテを見られます
5. 右上の **「ログアウト」** で終了

> メール確認が有効な場合、登録後に届くメールのリンクを承認してからログインしてください。

---

## 3. 基本の使い方A：録音して生成（おすすめ）

1. 上部のタブで **「録音して入力」** を選ぶ（初期状態で選ばれています）
2. **マイクのボタンをタップ** → 初回はブラウザのマイク許可を「許可」
3. 診療の会話を録音（録音中は経過時間と波形が表示されます）
4. もう一度タップで **停止** → 自動で **「文字起こし中…」→「SOAP生成中…」** と進みます
5. 右側に **S / O / A / P** が表示されます
6. 文字起こしの結果は「手入力」欄に入るので、**聞き取り違いがあれば直して再生成**できます

---

## 4. 基本の使い方B：手入力（録音が使えない時）

1. タブで **「手入力」** を選ぶ
2. テキスト欄に診療の会話を貼り付け／入力
3. **「SOAPを生成」** を押す

> 録音が使えない端末・環境でも、手入力で同じSOAP生成が使えます。

---

## 5. テンプレート（処置別）の選び方

生成ボタンの上で、処置に合ったテンプレートを選べます。内容が処置別に最適化されます。

- **初診** … 主訴・経過の問診と初診時の基本診査
- **再診** … 前回処置後の経過
- **メンテナンス(SPT)** … 歯周検査・SPTの計画
- **補綴** … 支台歯・適合・咬合・補綴ステップ
- **根管治療** … 歯髄/根尖の状態・根管治療のステップ

---

## 6. 補足メモ（任意）

「補足メモ」欄に **既往歴・アレルギー** 等を入れると、生成結果（特に O / A / P）に反映されます。
例）`既往歴：高血圧で内服中／アレルギー：特になし`

---

## 7. 生成結果の確認とコピー

- 結果は **S（主訴・問診）/ O（口腔内所見）/ A（評価・診断）/ P（治療計画）** の4ブロック
- 内容を確認・加筆のうえ、**「コピー」** で全文をクリップボードにコピー → カルテへ貼り付け
- 「レセコンに転記」は連携を想定した表示です

---

## 8. 保存したカルテを見る

- ログイン中は、生成したカルテが**自動で保存**されます
- 右上の **「保存カルテ」** から一覧 → 項目をタップで詳細（SOAP）を表示
- 詳細画面で **削除** も可能
- **別の端末**でも同じアカウントでログインすれば、同じカルテにアクセスできます

---

## 9. うまくいかない時（トラブル対処）

| 症状 | 対処 |
|---|---|
| マイクが使えない／録音できない | ブラウザのマイク許可を確認。`https://` でアクセスしているか確認。ダメな時は **「手入力」** を利用 |
| 「文字起こしに失敗しました」 | 通信状況を確認して再録音。はっきり話す。長すぎる録音は短く分ける |
| 「生成に失敗しました」 | 少し待って「もう一度試す」。会話が空でないか確認 |
| 「本日の生成上限に達しました」 | 1日の上限に達しています。翌日に再開、または管理者へ相談 |
| 「リクエストが多すぎます」 | 短時間に集中しすぎです。少し時間をおいて再実行 |
| ログインが切れた／弾かれる | 再度ログインしてください |

---

## 10. 注意事項

- **下書きであり、最終確認は歯科医師**が行ってください（特に A：評価・診断）
- 入力・生成内容は**診療目的にのみ**利用してください
- 患者の診療情報を扱うため、**共有端末ではログアウト**を徹底してください
- 現在は**ベータ版**です。歯科用語の文字起こしに誤りが出ることがあります（確認・修正のうえご利用ください）
