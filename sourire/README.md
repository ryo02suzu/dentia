# Sourire — 歯科の口コミ・MEO集患を AI で自動運用するシステム（試作）

by **Sourirette**。レセコン・電子カルテ連携は**不要**。医院の「Google という公開資産」だけを扱う。

## できること（試作）
- **ダッシュボード**：口コミ件数・★平均・マップ順位・未返信数、口コミ推移
- **口コミ管理**：新着口コミに **AI が返信案を自動生成** → 確認・修正して投稿（低評価は丁寧対応を促す）
- **MEO投稿**：テーマを選ぶと **AI が Google 投稿文を生成** → 予約投稿
- **★を増やす**：口コミ獲得 QR と受付スクリプト（やらせ・gating はしない正攻法）

すべて医療広告ガイドライン／ステマ規制に配慮したプロンプト設計。

## 動かし方
```bash
cd sourire
npm install
cp .env.example .env   # ANTHROPIC_API_KEY を設定
npm start              # http://localhost:3100
```

## 本番に向けて
- 口コミ取得・自動返信・順位/アクセスは **Google ビジネスプロフィール API**（要・利用申請）に接続。
- 患者データには触れない設計なので、レセコン連携なしで成立する。
