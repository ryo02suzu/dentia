# 納品プレイブック（AIで実働を8割削る手順＋プロンプト集）

> これを見れば、1院ぶんの作業が**1日30分**で回る。文章はぜんぶAI（ChatGPT / dentia）に作らせ、
> あなたは「確認して投稿する」だけ。コピペで使えるプロンプトを載せた。

---

## A. 口コミ返信代行（Google）

**手順**：①未返信の口コミを見る → ②下のプロンプトでAIに返信文を作らせる → ③医院トーンに直して投稿。

**AIプロンプト（コピペ）**
```
あなたは日本の歯科医院の受付担当です。次のGoogle口コミに、医院として返信文を作って。
条件：
- 丁寧・温かい・短め（2〜4文）。来院のお礼＋具体に一言触れる＋また気軽に来てほしい旨。
- 治療効果を断定しない／医療広告ガイドラインに配慮（「治る」「No.1」等は使わない）。
- 個人が特定される内容（病名・治療内容）は書かない。
- 低評価には、不快にさせたお詫び＋改善する姿勢＋「直接お話を伺いたい」旨を、言い訳せず誠実に。
口コミ本文：「{ここに口コミを貼る}」（★{評価}）
```

**ポイント**：星が低い口コミほど丁寧に返信する＝**他の見込み患者が「誠実な医院だ」と判断する**。返信率100%を目標に。

## B. MEO投稿（Googleビジネスプロフィール 月8本）

**手順**：月初に8本まとめて作る → 週2回投稿予約。ネタは下の型から回す。

**月8本のネタ型**
1. 予防・メンテの大切さ（リコール誘導）
2. よくある質問（例：親知らず／知覚過敏／歯ぎしり）
3. 医院の設備・衛生（滅菌・個室など安心材料）
4. スタッフ・院内の雰囲気（人柄を見せる）
5. 自費メニューの紹介（ホワイトニング・矯正相談 等／効果は断定しない）
6. 季節ネタ（新生活・年末年始・夏の着色 等）
7. 診療時間・予約・アクセスの案内（実用）
8. 小児・定期健診・フッ素 等のファミリー訴求

**AIプロンプト（コピペ）**
```
あなたは歯科医院のSNS/Google投稿担当です。Googleビジネスプロフィール用の投稿文を1本作って。
テーマ：「{上の型から1つ}」／医院名：{}／地域：{}
条件：
- 250〜400字。患者目線でやさしく、専門用語は噛み砕く。
- 最後に自然な行動喚起（ご予約・お気軽にご相談・定期検診を）を1文。
- 医療広告ガイドライン配慮（治療効果の断定・体験談・比較優良・誇大はNG）。
- ハッシュタグや絵文字は控えめに。地域名を1回入れる（MEO対策）。
```

## C. リコール／離脱患者の掘り起こし（LINE / SMS / ハガキ）★一番効く

**手順**：①医院で「最終来院が◯ヶ月以上前」の患者を抽出（医院側の作業）→ ②下で文面をAI生成 → ③医院がLINE/SMS/ハガキで送信。**個人情報は医院の中で扱う**（あなたはリストを持ち出さない）。

**AIプロンプト（コピペ）**
```
歯科医院から、最後の来院から{6}ヶ月以上経った患者さんへ送る、定期検診の再来院をうながす短文を作って。
媒体：{LINE / SMS / ハガキ}（SMSは70字目安、LINEは150字目安、ハガキは少し丁寧に）
条件：
- 押し付けがましくない。「お変わりないですか」＋「定期的なチェックで予防になります」＋「ご予約お待ちしています」。
- 不安を煽らない、治療を断定しない（医療広告配慮）。
- 予約方法（電話/LINE/Web）を1つ入れる。医院名と一言の温かさ。
3パターン（あっさり/標準/丁寧）で出して。
```

**なぜ効くか**：新規をお金で買うより、**一度来た患者を呼び戻す方が圧倒的に安い・早い**。送信数→再来院数が**数字で出る**ので実績にしやすい。倒産原因1位の「販売不振」に直接効く。

## D. 月次レポート（5分・これが継続課金の理由になる）

毎月この6行を医院に送るだけ：
1. Google口コミ：先月◯件 → 今月◯件（★平均◯）
2. マップ表示：主要KWで◯位前後
3. プロフィール経由のアクセス/電話：◯件（先月比）
4. 投稿：◯本実施
5. リコール送信：◯件 → 再来院◯名（推定売上◯円）
6. 来月やること：◯◯

→ 「**数字が見える**」だけで解約されにくくなる。Googleビジネスプロフィールの「インサイト」から取れる。

## E. 1院あたりの作業時間の目安（労働集約を軽くする）
- 口コミ返信：来た時だけ・1件2分（AI下書き＋微修正）
- MEO投稿：月初にまとめて60分（8本）＋予約投稿
- リコール文面：月1回30分（3パターン作って医院に渡す）
- レポート：月1回15分
→ **1院 月あたり実働 約2時間**。10院でも週5〜6時間。AIがあるから1人で回せる。

## F. コンプラ早見（Aキットの#5と合わせて必読）
- 口コミは**正当な依頼までOK・やらせ/購入はNG**（ステマ規制）。
- 投稿・返信で**治療効果の断定／ビフォーアフター／体験談／比較優良はNG**（医療広告GL）。
- 患者リストは**医院の中で扱う**（個人情報・委託）。覚書を1枚交わすと安全。
- 「必ず増える」と言わない（成果非保証・景表法）。
