# STT 評価ハーネス（eval/）

dentia の文字起こし段（`/api/transcribe`）の精度を、**歯科の実用性**の観点で測るための
依存ゼロ・Node 製ツール一式。設計書 [docs/stt-migration-plan.md §5](../docs/stt-migration-plan.md) の評価計画を実装したもの。

> 目的：現行 Whisper・国産STT API・自前STT を**同一テストセットで横並び比較**し、
> A/B/C 選択や fine-tuning の go/no-go を**数値で**判断できるようにする。

## 構成

| ファイル | 役割 |
|---|---|
| `terms.js` | 歯科用語・歯番・左右のタグ抽出（採点の素材） |
| `score.js` | CER/WER・term-level・歯番/左右 取り違えの採点 CLI（依存ゼロ） |
| `dataset/sample.jsonl` | フォーマット見本（擬似サンプル、実音声なし） |

## 使い方

```bash
node eval/score.js eval/dataset/sample.jsonl
```

システムごとに指標が表で出る（複数システムは横並び）。

### データ形式（JSON Lines, 1行=1会話）

単一システム:
```json
{"id":"case-01","ref":"正解テキスト","hyp":"システム出力"}
```

複数システム横並び比較:
```json
{"id":"case-01","ref":"正解テキスト","hyps":{"whisper":"...","amivoice":"..."}}
```

- `ref` = 人手で作った正解。`hyp`/`hyps` = STT 出力。
- `//` 始まりの行と空行はコメントとして無視される。

### プログラムから使う

```js
const { cer, wer, scorePair, scoreDataset } = require("./eval/score");
const { extractTerms, extractTeeth, extractLaterality } = require("./eval/terms");
```

## テストセットの作り方（§5.2）

1. **選定**：β同意済み音声から **30〜50 会話**を抽出。
   診療タイプを **初診 / 再診 / SPT / 補綴 / 根管** でバランス良く（各タイプが偏らないように）。
2. **正解化**：各音声を**人手で完全な正解テキスト**に起こす（`ref`）。
   歯番・左右・検査値は特に慎重に（ここが臨床的に最重要）。
3. **用語タグ**：`terms.js` が歯科用語・歯番・左右を自動抽出するので、
   正解化の際は**正規表記**（`#46`・`EPT`・`Per`・`PD 4mm` 等）で書いておくと採点が安定する。
4. **凍結**：完成したら**固定し、学習には二度と使わない**（§4.3）。
   バージョン番号を付け、モデル/データの対応を記録（再現性）。
5. **格納**：1会話=1行の JSONL にして `eval/dataset/` 配下へ。
   `hyps` に各システムの出力を並べれば横並び比較できる。

各システムの出力（`hyps`）は、同一音声を
(現行Whisper) / (国産API) / (国産API+後処理) / (自前) に通して収集する（§5.3）。

## 各指標の読み方（§5.1）

| 指標 | 意味 | 見方 |
|---|---|---|
| **CER** | 文字誤り率（Levenshtein / 参照文字数）。日本語の主指標 | 小さいほど良い。全体の地力 |
| **WER** | トークン誤り率（補助） | 小さいほど良い。CER と併読 |
| **用語 recall** | 正解の歯科用語を出力がどれだけ拾えたか | 大きいほど良い。**実用性を最も左右** |
| **用語 precision** | 出力した用語のうち正しい割合 | 大きいほど良い（幻の専門語を出さない） |
| **用語 F1** | precision/recall の調和平均 | 用語精度の総合 |
| **用語 誤り率(1-recall)** | 正解用語の取りこぼし率 | 小さいほど良い |
| **歯番 取り違え率** | `#46`↔`#36` の取り違え・欠落・余剰 / 正解歯番数 | **臨床的に最も危険**。単独監視 |
| **左右 取り違え率** | 左↔右 の不一致 / 正解の左右数 | **危険指標**。単独監視 |

- 集計は**マイクロ平均**（CER/WER は距離合計÷参照長合計、用語/歯番/左右は TP/ref/hyp を全行合算）。
- term-level の**誤り率 = 1 - recall**（正解用語のうち落とした割合）と定義（`score.js` 参照）。
- **CER が良くても用語・歯番・左右が崩れていれば臨床的に無価値**。専門指標を必ず併読すること。

## 補正辞書との関係

`score.js` は STT 生出力でも後処理補正後（`stt/postprocess.js`）でも同じ形で測れる。
「国産API 単体」vs「国産API + 後処理」を `hyps` に並べれば、辞書の効きを定量化できる
（フェーズ2 の go/no-go 判断材料、設計書 §9）。
